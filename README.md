# Apple Documentation Scraper

## Why?

If you wanna vibe-code anything involving iOS or MacOS, you'll want to have all of the official documentation at-hand.

This saves the needed content to disk, as HTML (cleaned).

## Limitations

1. ~No Parallel Scraping (Very Slow)~
2. Not Documented
3. Likely To Break, No Test Suite Configured
4. No Additional Formatting on Docs, Filtering, Merging, etc.
5. Edge cases (ie, archived documentation, handling redirects, etc)

## Usage

`apple-doc-scraper --help`
